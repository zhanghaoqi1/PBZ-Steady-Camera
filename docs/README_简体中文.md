# 影之刃零：稳镜设置 — v0.1.2-beta

镜头专用测试版。在原生 Esc 菜单的「镜头设置」页中调整镜头距离、视野角增量、战斗抖动幅度和镜头坐标偏移，提供应用、取消、稳镜预设和恢复原版。

本包仅包含镜头功能，不含 Boss 再战、技能/AI/伤害修改、开发探针、资源密钥、个人配置或存档。运行时使用游戏自带的 Puerts，不需要额外安装 UE4SS、ModEngine 或注入 DLL。

## 兼容范围

- Windows x64 / Steam；已适配的基础版本：Steam Build **26266538**，游戏 **CL-301524_JKS-17219**，UE **5.7.4**。
- 其他游戏版本、平台及后续更新未验证。游戏更新后，两个原版脚本入口可能改变。
- 这是 **beta 测试版**。本独立包通过了自动行为测试、依赖检查及 PAK 解包哈希比对；同源镜头逻辑与原生菜单此前已实机验证。**拆分后的独立发行包尚未重新完成安装到游戏启动的全流程实机走查。**
- 本次扩大了距离和视野角范围，加入暂停菜单内的应用预览，并将镜头坐标偏移扩展到 ±300 cm。同源组合开发版已于2026-11-02完成菜单内预览、恢复原版及 Esc 取消的实机验证；独立包仍需单独完成安装验证。

## 安装

1. 完全退出游戏。
2. 如果安装过旧组合开发版，先移除其三个文件：`zz_PBZCombat_P.pak`、`zz_PBZCombat_P.utoc`、`zz_PBZCombat_P.ucas`。**不要同时安装组合版与本独立版。**
3. 将压缩包中的 `ProjectPBZ` 文件夹复制到游戏根目录（Steam「浏览本地文件」打开的 PBZ 文件夹）。最终应得到：

```text
PBZ/
└─ ProjectPBZ/Content/Paks/~mods/
   ├─ zz_PBZCamera_P.pak
   ├─ zz_PBZCamera_P.utoc
   └─ zz_PBZCamera_P.ucas
```

4. 三个文件必须一起保留；没有 `~mods` 文件夹时自行创建。不要放进 `platform/steam`，不要覆盖原版容器。
5. 正常通过 Steam 启动游戏，进入存档，按 Esc，选择最右侧「镜头设置」。

## 使用

| 选项 | 范围 | 每档 | 首次默认值 |
|---|---|---|---|
| 战斗镜头距离 | 原版的 90%–200% | 5% | 110% |
| 视野角增量 | 原版基础上 +0° 至 +40° | 1° | +0° |
| 战斗抖动幅度 | 0%–100% | 10% | 60% |
| 镜头水平偏移（X） | -300 至 +300 cm | 5 cm | 0 |
| 镜头垂直偏移（Y） | -300 至 +300 cm | 5 cm | 0 |

拖动滑条或点击左右箭头调整，选择「应用」后保存，并立即刷新设置页背景中的镜头，无需退出菜单。暂停画面保留原版模糊与暗角。「取消」、切换页签或 Esc 返回会放弃未应用的修改。「恢复原版」只改草稿，需再点「应用」，对应距离100%、FOV增量0°、抖动100%、XY偏移归零。

坐标偏移以厘米为单位，每档 5 cm：负的 X 让人物向右移动（镜头相对左移），正的 Y 抬高镜头、人物在画面中下移；0 为原版。偏移量较大（接近 ±300 cm）时，镜头可能穿过门框、墙壁或天花板，与原版镜头一样不做碰撞修正。

独立配置保存在 `%LOCALAPPDATA%\ProjectPBZ\Saved\PBZCamera.json`。不附带发布者的个人配置，也不自动导入旧组合版的配置。

只修改识别出的常规游戏镜头；未知、处决及剧情镜头不强行覆盖。不同场景的原生镜头行为可能不同，本版本尚未完成所有场景和 Boss 的体验验证。手柄完整导航、超宽屏等也未全面验收。

## 冲突

本包替换 `UI/Widget/SystemBase.js` 与 `Gameplay/GameModeBuild.js`，新增六个 `PBZCamera` 模块。替换相同脚本的其他 Mod 可能覆盖本包；其他运行时相机 Mod 也可能相互影响。遇到入口缺失或镜头异常时先单独安装本包测试，不要通过反复改文件名叠加多个版本。

## 卸载与复位

关闭游戏，仅删除 `~mods` 中的三个 `zz_PBZCamera_P` 文件，然后正常启动。不要删除原版 PAK/UTOC/UCAS。配置文件可以保留；如需恢复本 Mod 首次默认值，关闭游戏后删除 `PBZCamera.json`。诊断文件为同目录的 `PBZCamera-diagnostics.txt`，可选删除。

## 校验与反馈

`MANIFEST.json` 列出容器哈希、资源清单和验证范围；`SHA256SUMS.txt` 提供本包文件的 SHA-256。反馈时请提供游戏 Build/CL、是否同时安装其他 Mod，以及复现步骤。此包没有联网、更新器或遥测功能。
